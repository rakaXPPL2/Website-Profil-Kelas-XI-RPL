AC. REFLEKSI INDIVIDU

1. Apa perbedaan bekerja sendiri dengan bekerja menggunakan Git dan GitHub?
Bekerja sendiri membuat saya lebih bebas mengatur pekerjaan, sedangkan menggunakan Git dan GitHub membuat pekerjaan lebih teratur dan memudahkan saya bekerja sama dengan anggota kelompok.

2. Apa manfaat branch?
Branch bermanfaat untuk mengerjakan bagian atau fitur tertentu tanpa mengubah kode utama.

3. Mengapa Pull Request diperlukan?
Pull Request diperlukan agar perubahan yang dibuat dapat diperiksa dan disetujui sebelum masuk ke kode utama.

4. Apa manfaat Code Review?
Code Review membantu menemukan kesalahan dan memberikan masukan agar kode menjadi lebih rapi dan baik.

5. Error apa yang paling sulit kalian selesaikan?
Error yang paling sulit saya selesaikan adalah ketika program tidak berjalan sesuai hasil yang diharapkan meskipun kode terlihat sudah benar.

6. Bagaimana kalian menemukan solusinya?
Saya menemukan solusinya dengan mengecek kode satu per satu, membaca pesan error, mencoba beberapa cara, dan berdiskusi dengan teman.

7. Apa kontribusi terbesar kalian dalam kelompok?
Kontribusi terbesar saya adalah mengerjakan bagian yang diberikan kepada saya dan membantu kelompok ketika ada masalah pada kode.

8. Jika menjadi programmer profesional, kebiasaan apa dari kegiatan ini yang akan kalian pertahankan?
Saya akan mempertahankan kebiasaan menggunakan Git, membuat commit secara rutin, melakukan pengecekan kode, dan bekerja sama dengan anggota tim.
